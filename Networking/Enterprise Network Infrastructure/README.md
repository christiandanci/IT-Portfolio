# Enterprise Network Infrastructure

## Overview

Designed and implemented an enterprise network using Cisco Packet Tracer, incorporating multiple departments, core network services, and server infrastructure. The project demonstrates the planning, configuration, deployment, and validation of a functional enterprise network environment.

## Technologies Used

- Cisco Packet Tracer
- IPv4 Networking
- DHCP
- DNS
- HTTP
- SMTP / POP3

## Skills Demonstrated

- Enterprise network design
- Network infrastructure deployment
- DHCP configuration
- DNS configuration
- Email server deployment
- Web server deployment
- Network troubleshooting
- Inter-department connectivity
- Infrastructure validation

## Validation

The complete enterprise network was fully tested following deployment. Validation included:

- DHCP address assignment
- DNS name resolution
- End-to-end network connectivity
- Email service functionality
- Web server accessibility
- Inter-department communication

To keep this portfolio concise, representative screenshots demonstrating successful configuration and validation have been included rather than every individual test performed.
