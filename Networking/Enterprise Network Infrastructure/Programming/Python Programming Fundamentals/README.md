# Python Programming Fundamentals

## Overview

Developed a collection of Python applications demonstrating core programming concepts, algorithm design, software development techniques, and debugging practices.

This project showcases practical implementation of procedural programming, object-oriented programming (OOP), event-driven programming, algorithm development, flowchart design, and Python application development.

## Technologies Used

- Python
- IDLE (Python IDE)
- Algorithms
- Flowcharts
- Procedural Programming
- Object-Oriented Programming (OOP)
- Event-Driven Programming

## Skills Demonstrated

- Python application development
- Algorithm design
- Flowchart creation
- Procedural programming
- Object-oriented programming (OOP)
- Event-driven programming
- Variables and data types
- Conditional statements
- Loops and iteration
- Functions and methods
- User input validation
- Debugging and testing
- Code documentation
- Python coding standards (PEP 8)

## Validation

All applications were tested using multiple input scenarios to verify correct functionality, logical accuracy, and expected outputs.

Debugging techniques were applied to identify and resolve syntax, logical, and runtime errors while following structured programming practices.
