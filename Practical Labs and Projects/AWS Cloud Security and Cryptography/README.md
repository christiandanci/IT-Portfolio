\# AWS Cloud Security and Cryptography



\## Overview



This practical work was completed as part of my Level 5 HND in Digital Technologies (Cybersecurity) and focused on implementing and testing security controls within Amazon Web Services (AWS).



The work covered cloud access control, data protection, encryption, monitoring, compliance, notifications, and automated security remediation using a range of AWS services.



\## Practical Work



The practical activities included:



\- Configuring and reviewing Amazon S3 bucket permissions

\- Managing S3 public access controls and bucket policies

\- Testing access to cloud-hosted resources

\- Working with Amazon EC2 instances

\- Working with Amazon EBS volumes and snapshots

\- Creating and managing AWS KMS encryption keys

\- Applying encryption controls to AWS resources

\- Configuring Amazon SNS topics and subscriptions

\- Configuring AWS Config

\- Creating AWS Config rules for compliance monitoring

\- Monitoring AWS resources for configuration and security compliance

\- Implementing automated remediation for non-compliant resources

\- Testing security configurations and validating successful implementation
