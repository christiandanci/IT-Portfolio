# \# Networking in the Cloud

# 

# \## Overview

# 

# This project was completed as part of my Level 5 HND in Digital Technologies (Cybersecurity) and focused on designing, deploying, securing, and testing a cloud-based application environment using Amazon Web Services (AWS).

# 

# The project provided practical experience across cloud networking, compute, database services, security, scalability, monitoring, application deployment, and performance testing.

# 

# \## Practical Work

# 

# The project involved:

# 

# \- Creating and configuring an AWS Virtual Private Cloud (VPC)

# \- Configuring public subnets

# \- Creating and configuring route tables

# \- Creating and attaching an Internet Gateway

# \- Enabling VPC DNS and DNS hostnames

# \- Creating and configuring Amazon EC2 instances

# \- Provisioning a web server

# \- Configuring Security Groups

# \- Creating and configuring an Amazon RDS database

# \- Migrating application data to the database

# \- Using AWS Secrets Manager

# \- Creating an Application Load Balancer

# \- Implementing Amazon EC2 Auto Scaling

# \- Monitoring EC2 instance performance

# \- Deploying and testing a cloud-hosted application

# \- Performing application load testing

# \- Testing network performance and reliability

# \- Producing cloud architecture documentation
