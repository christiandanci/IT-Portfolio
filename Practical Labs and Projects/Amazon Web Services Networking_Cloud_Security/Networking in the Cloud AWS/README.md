# Networking in the Cloud

## Overview

Designed and configured cloud networking services using Amazon Web Services (AWS). The project demonstrates cloud network design, connectivity, security, and infrastructure deployment within a cloud environment.

## Technologies Used

- Amazon Web Services (AWS)
- Amazon VPC
- Subnets
- Route Tables
- Internet Gateway
- Security Groups
- Network ACLs
- EC2

## Skills Demonstrated

- Cloud networking
- Virtual Private Cloud (VPC) configuration
- Network segmentation
- Security Group configuration
- Route table configuration
- Cloud infrastructure deployment
- Connectivity validation

## Validation

The cloud networking environment was fully configured and tested. Representative screenshots have been included to demonstrate successful deployment and validation of the networking components.
