\# Cybersecurity



\## Overview



This section contains practical cybersecurity work completed as part of my Level 5 HND in Digital Technologies (Cybersecurity).



The module combined cybersecurity theory with practical implementation, configuration, testing, and validation of security controls within a Windows-based environment.



The practical work demonstrates the application of security principles to systems administration, endpoint security, access control, network security, policy enforcement, and organisational security.



\## Practical Project



\### Windows Server Security and Administration



The `Windows-Server-Security-and-Administration` folder contains a practical Windows security project completed using Windows Server 2019 and Windows 10 virtual machines.



The project involved configuring, implementing, and testing security controls within a Windows domain environment.



Practical activities included:



\- Windows Server 2019 configuration

\- Windows 10 client configuration

\- Windows domain administration

\- Group Policy configuration and enforcement

\- Password policy implementation

\- User and administrative access control

\- USB and removable-storage restrictions

\- Control Panel restrictions

\- Windows Update policy configuration

\- Shared folder and resource access

\- Network security restrictions

\- Policy deployment and validation

\- Security testing and troubleshooting
