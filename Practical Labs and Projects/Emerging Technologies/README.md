\# Emerging Technologies



\## Overview



This section contains practical coursework completed as part of my Level 5 HND in Digital Technologies (Cybersecurity).



The Emerging Technologies module involved researching developing technologies and applying technical concepts through the design, development, implementation, and testing of a practical alarm system.



The project combined hardware, programming, sensor input, visual and audible alerts, simulation, physical implementation, testing, and technical presentation.



\## Practical Project



\### Sensor-Based Alarm System



The practical project involved developing an Arduino-based alarm and monitoring system capable of responding to sensor input and communicating different system states to the user.



The completed system used visual and audible indicators to represent safe, warning, and danger conditions.



\## Practical Work



The project included:



\- Designing an Arduino-based alarm system

\- Working with an Arduino Uno board

\- Connecting and configuring sensor hardware

\- Implementing LED status indicators

\- Implementing an audible buzzer alert

\- Using an LCD display to communicate system status

\- Programming system behaviour and alert logic

\- Implementing safe, warning, and danger states

\- Testing sensor responses

\- Testing visual and audible alerts

\- Simulating components and system behaviour using Wokwi

\- Building and testing the physical system

\- Troubleshooting the implementation

\- Documenting the completed solution

\- Presenting the project and its development
