\# Big Data



\## Overview



This section contains practical data analysis and Big Data coursework completed as part of my Level 5 HND in Digital Technologies (Cybersecurity).



The work involved analysing structured datasets, preparing and organising data, using Microsoft Excel for data analysis, creating PivotTables, filtering and comparing data, and producing visualisations to communicate findings.



The module also explored wider Big Data concepts and the use of data to support analysis and decision-making.



\## Practical Work



The practical work included:



\- Working with structured datasets in CSV and Excel formats

\- Preparing and organising data for analysis

\- Filtering and sorting datasets

\- Analysing income data across different demographic groups

\- Comparing income by age group

\- Analysing gender distribution among high-income earners

\- Analysing geographical differences in income

\- Creating PivotTables

\- Grouping and summarising data

\- Creating charts and visualisations

\- Presenting analytical findings

\- Producing practical evidence of the analysis process
