\# Business Intelligence



\## Overview



This section contains practical Business Intelligence coursework completed as part of my Level 5 HND in Digital Technologies (Cybersecurity).



The practical work focused on preparing, transforming, analysing, and visualising data using Microsoft Excel and Microsoft Power BI.



The project demonstrates the development of a Business Intelligence workflow from initial dataset preparation through to interactive dashboard creation and the interpretation of data insights.



\## Practical Work



The practical activities included:



\- Working with carbon emissions data

\- Reviewing raw data prior to analysis

\- Cleaning and preparing data using Microsoft Excel

\- Importing Excel data into Microsoft Power BI

\- Transforming data for analysis

\- Creating Power BI visualisations

\- Developing an interactive dashboard

\- Implementing dashboard slicers

\- Adding cards and additional visual elements

\- Improving dashboard layout and usability

\- Testing interactive filtering

\- Analysing information presented through Power BI visuals

\- Identifying and presenting insights from the data

\- Presenting the completed Business Intelligence work

\## Business Intelligence Workflow



The practical evidence demonstrates a workflow involving:



1\. Reviewing the original dataset

2\. Cleaning and preparing data in Excel

3\. Connecting Power BI to the prepared Excel workbook

4\. Importing and transforming data

5\. Creating initial visualisations

6\. Building a Power BI dashboard

7\. Adding interactive slicers and cards

8\. Improving the dashboard design

9\. Testing interactive filtering

10\. Analysing and presenting insights from the resulting visualisations
