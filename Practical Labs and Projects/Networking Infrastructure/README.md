\# Networking Infrastructure



\## Overview



This section contains practical networking and infrastructure work completed as part of my Level 5 HND in Digital Technologies (Cybersecurity).



The module involved the design, implementation, configuration, security, testing, and documentation of simulated enterprise network environments using Cisco Packet Tracer.



The work demonstrates practical understanding of network infrastructure from initial logical and physical design through to service configuration, connectivity testing, security implementation, troubleshooting, and ongoing maintenance planning.



\## Practical Projects



\### Cisco Packet Tracer Network Implementation



This project focused on designing and implementing an enterprise network environment supporting multiple departments and network services.



The work included:



\- Logical network design

\- Physical network design

\- Departmental network connectivity

\- IP addressing

\- DHCP configuration

\- DNS configuration

\- Email server configuration

\- Web server configuration

\- Static server addressing

\- Inter-department connectivity testing

\- Network service validation

\- Physical server-rack planning

\- Network maintenance planning



Supporting evidence is available within:



`Cisco-Packet-Tracer-Network-Implementation/`
